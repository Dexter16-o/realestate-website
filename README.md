# Bhavesh Property 🏠

A modern, responsive real-estate website for **Bhavesh Property**, designed to help buyers, sellers, and renters discover property opportunities and contact the agent easily.

## ✨ Features

- Modern responsive real-estate website
- Buy, Rent, Sell and Investment enquiry options
- Featured property listings
- Property search and filters
- Property enquiry/contact form
- WhatsApp and click-to-call integration
- Responsive mobile navigation
- Email enquiry notifications using Resend
- Progressive Web App (PWA) support
- Installable as an app on supported devices
- Service Worker support
- Custom app icons
- Secure environment variables for API keys
- Deployed online using Render

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Resend
- Progressive Web App (PWA)
- Render
